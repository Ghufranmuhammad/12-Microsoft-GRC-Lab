# Control: Access Control Policy & Procedures
Evidence Required: Evidence demonstrating logical access controls and user provisioning lifecycle.
Evidence Owner: IT Security / IAM Team
Evidence Type: Configuration Export / User Access Audit Log
Review Frequency: Bi-annual
Testing Approach: Audit a sample of user accounts for proper provisioning/deprovisioning.
Expected Result: Access is granted based on the principle of least privilege.
Failure Condition: Unauthorized access or orphaned accounts found.
