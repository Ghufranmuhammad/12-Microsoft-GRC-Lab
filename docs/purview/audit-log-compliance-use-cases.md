# Audit Log Compliance Use Cases

### Use Case 1 — Privileged Access
* **Control:** Privileged activities must be monitored.
* **Evidence:** Audit records showing administrator activity.
* **GRC Purpose:** Demonstrate monitoring and support investigations.

### Use Case 2 — User Account Changes
* **Control:** Account provisioning must be authorized and tracked.
* **Evidence:** Audit logs showing user creation, deletion, or group membership changes.
* **GRC Purpose:** Prevent unauthorized account creation or privilege escalation.

### Use Case 3 — File Access
* **Control:** Access to sensitive or confidential data must be logged.
* **Evidence:** Audit records of access events (view/download) for labeled files.
* **GRC Purpose:** Detect potential data exfiltration or unauthorized viewing.

### Use Case 4 — Policy/Configuration Changes
* **Control:** Modifications to security settings must be tracked.
* **Evidence:** Audit logs showing updates to Conditional Access policies or Purview settings.
* **GRC Purpose:** Prevent accidental or malicious weakening of the security posture.

### Use Case 5 — Investigation after Suspected Unauthorized Activity
* **Control:** Anomalous behavior must be systematically investigated.
* **Evidence:** Audit log export containing all activities performed by a specific user account over a given timeframe.
* **GRC Purpose:** Support incident response by establishing a clear, verifiable timeline of actions taken during a security event.
